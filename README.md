# LIFE

Eén app die je werk, sport, gezin en vrije tijd op elkaar afstemt. Je ziet niet alleen wat je
moet doen, maar ook wat je vandaag beter níét kunt doen. Elke ochtend een dagplan dat je echt
kunt halen.

Onderdeel van het LuzeX-platform; zie de hub voor hoe de projecten samenhangen.

## Stand van zaken

Alleen ontwerp. Er is nog geen applicatiecode.

- [`docs/planregels.md`](docs/planregels.md) — hoe LIFE rekent: haalbaarheid, wat eruit moet,
  wat nooit geschrapt wordt. Concept; open vragen staan erin.
- [`ontwerp/verkooppagina-concept.html`](ontwerp/verkooppagina-concept.html) — de verkooppagina
  als parallax-tocht door één dag. Één bestand, open het in een browser. Alle namen, tijden
  en cijfers erin zijn verzonnen voorbeelden.

## Volgende stappen

1. Planregels vastleggen (de vier open vragen onderaan het planregels-document).
2. Dashboard ontwerpen: dagplan, "liever niet" en de week.
3. Pas daarna de backend, in dezelfde stack als ACCRD, CMMNTY en RSLNT.
